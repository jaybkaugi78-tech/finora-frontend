# Finora Frontend — Full V1 Integration

Connected to the Flask/PostgreSQL backend.

## Included
- Register + login
- JWT protected routes
- Logout
- Accounts
- Income, expense and transfer transactions
- Real dashboard data
- Budgets
- Goals + contributions
- Bills/subscriptions
- Analytics
- Notifications
- Profile/settings

## Run
```bash
npm install
npm run dev
```

Backend expected at `http://127.0.0.1:5000/api`.
