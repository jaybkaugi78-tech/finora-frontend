# Finora Frontend

Modern personal finance dashboard built with React + Vite.

## Run

```bash
npm install
npm run dev
```

## Included now

- Responsive Finora dashboard
- Transactions
- Budgets
- Savings goals
- Accounts
- Bills & subscriptions
- Analytics
- Settings
- Login + register screens
- Desktop sidebar + mobile navigation
- Mock data layer
- API helper ready for the Flask backend

## Backend URL

The API helper defaults to `http://127.0.0.1:5000/api`.
Later you can set `VITE_API_BASE_URL` in an `.env` file.
